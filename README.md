# NEON BLAST LABYRINTH

日本語 | English | 简体中文 | 繁體中文

## 日本語

これは、index.html をブラウザで開くだけで遊べる Three.js 製ボンバーマン系ゲームです。

### ファイル構成

- index.html: ゲーム本体

### 動作環境

- PC とスマートフォンで動作する想定です。
- スマートフォンでは横画面で利用してください。
- Three.js を CDN から読み込むため、インターネット接続が必要です。
- 画面が小さい端末では、ブラウザのフルスクリーン表示を推奨します。

### 遊び方

- PC: WASD または矢印キーで移動、Space でボム設置、P または Esc で一時停止
- スマートフォン: 左側のジョイパッドエリアで移動、右下の B ボタンでボム設置
- 目標: 敵をすべて消し、出口リングを緑にしてゴールへ向かう

### 対応言語

- 日本語
- English
- 简体中文
- 繁體中文

### 言語の切り替え方法

- メニュー画面または一時停止画面で言語を選択できます。
- 言語設定は保存データに反映されます。

### サウンド

- サウンド ON / OFF を切り替えられます。
- 効果音は Web Audio API で生成しています。
- 一部のブラウザでは、初回のタップやクリックで音声出力を許可する必要があります。

### 保存データ

- ステージ進行状況、ハイスコア、言語設定、サウンド設定はブラウザのローカルストレージに保存されます。
- 続行を使うと、前回保存したステージから再開できます。
- ブラウザのサイトデータやストレージを削除すると、保存データも消えます。

### ゲーム機能

- 多数ステージ
- 多数の敵キャラクター
- ボム数、火力、速度、爆弾時間、生命を増やすアイテム
- 爆発連鎖
- 一時停止
- ローカルセーブ
- 横画面最適化

### 注意

- ローカル保存データはブラウザ単位で保存されます。
- 端末やブラウザを替えたり、ブラウザのキャッシュ・サイトを削除すると、引き継ぎできなくなる場合があります。

## English

This is a Three.js bomb action game that can be played by opening index.html in a browser.

### File Structure

- index.html: main game file

### Runtime

- Designed for desktop browsers and mobile browsers.
- Mobile play requires landscape orientation.
- Internet access is required because Three.js is loaded from a CDN.
- On small screens, browser fullscreen display is recommended.

### Controls

- PC: WASD or arrow keys to move, Space to place a bomb, P or Esc to pause
- Mobile: move with the left joystick area, place a bomb with the B button
- Goal: defeat all enemies, make the exit ring green, and reach the goal

### Supported Languages

- Japanese
- English
- Simplified Chinese
- Traditional Chinese

### Language Switching

- Language can be changed from the menu screen or the pause screen.
- Language settings are included in saved data.

### Sound

- Sound can be toggled on or off.
- Sound effects are generated with Web Audio API.
- Some browsers require the first tap or click before allowing audio playback.

### Save Data

- Stage progress, high score, language settings, and sound settings are saved in browser local storage.
- Continue can restore the previously saved stage.
- Deleting browser site data or storage removes the saved progress.

### Features

- Many stages
- Many enemy types
- Powerups for bombs, fire range, speed, fuse time, and extra lives
- Chain explosions
- Pause
- Local save
- Landscape-oriented mobile design

### Notes

- Save data is stored per browser.
- Changing devices, browsers, or deleting site data may prevent progress from being carried over.

## 简体中文

这是一个只需用浏览器打开 index.html 即可游玩的 Three.js 炸弹动作游戏。

### 文件构成

- index.html: 游戏主文件

### 运行环境

- 支持桌面端和移动端浏览器。
- 手机端请使用横屏游玩。
- Three.js 从 CDN 加载，因此需要网络连接。
- 小屏幕设备建议使用浏览器全屏显示。

### 操作方式

- PC: WASD 或方向键移动，空格键放置炸弹，P 或 Esc 暂停
- 手机: 左侧方向区域移动，右下 B 按钮放置炸弹
- 目标: 消灭所有敌人，让出口环变绿并抵达终点

### 支持语言

- 日语
- English
- 简体中文
- 繁體中文

### 切换语言

- 可在菜单界面或暂停界面选择语言。
- 语言设置会保存到存档数据中。

### 声音

- 可开启或关闭声音。
- 音效通过 Web Audio API 生成。
- 部分浏览器需要先点击或触摸一次，才允许播放声音。

### 存档数据

- 关卡进度、最高分、语言设置、声音设置会保存到浏览器本地存储。
- 使用继续功能可以从上次保存的关卡重新开始。
- 删除浏览器站点数据或本地存储时，存档也会被删除。

### 游戏功能

- 大量关卡
- 多种敌人
- 增加炸弹数、爆炸范围、移动速度、缩短引信、增加生命等道具
- 连锁爆炸
- 暂停
- 本地存档
- 横屏移动端优化

### 注意事项

- 存档数据按浏览器保存。
- 更换设备、更换浏览器或删除站点数据后，可能无法继续游戏。
